# Third-party notices

## Fonts

`lib/skin.css` embeds two WOFF2 font files as base64 data URIs:

| Font | Files | License |
| :--- | :--- | :--- |
| **Crimson Pro** | `assets/fonts/crimson.woff2`, `assets/fonts/crimson-italic.woff2` | SIL Open Font License 1.1 — see `assets/fonts/OFL-CrimsonPro.txt` |
| **DM Sans** | `assets/fonts/dmsans.woff2` | SIL Open Font License 1.1 — see `assets/fonts/OFL-DMSans.txt` |

Both fonts are distributed via Google Fonts and remain under the SIL Open Font
License 1.1; only the latin subset is bundled here.

## Design inspiration

The color palette and typography direction are *inspired by* Claude (Anthropic)
and by publicly documented design tokens of that product. This plugin is an
independent community project: it is **not affiliated with, endorsed by, or
sponsored by Anthropic**, and it ships **no Anthropic assets** (no logos, no
proprietary fonts, no copied artwork).

The plugin targets the DeepSeek Harness (DSH) Web GUI. DSH itself is a separate
